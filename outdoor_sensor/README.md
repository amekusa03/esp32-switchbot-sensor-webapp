# 🌿 ベランダ環境センサー (子機: outdoor_sensor)

ESP32-C3 を用いた、電池駆動・ESP-NOW 無線送信のベランダ環境センサーです。
5分おきに Deep Sleep から一瞬だけ起床し、照度・外気温・電池電圧を親機 (Hub) へ送信して即座に就寝します。

---

## 🔌 ハードウェア接続 (ピン配置)

ESP32-C3 (XIAO ESP32C3 推奨) のピン接続:

| ESP32-C3 ピン | 接続部品・回路 | 役割 |
| :--- | :--- | :--- |
| **3.3V (3V3)** | CdS の片足、サーミスタの片足 | センサー電源 |
| **GPIO1 (ADC1_CH1)** | CdS と 9.1kΩ プルダウン抵抗の接続点 | 照度 (Lux) 計測 |
| **GPIO3 (ADC1_CH3)** | B3950 サーミスタ と 10kΩ 抵抗の接続点 | 外気温 (℃) 計測 |
| **GPIO0 (ADC1_CH0)** | (任意) 電池電圧の 1/2 分圧抵抗接続点 | 電池残量 (V) 計測 |
| **GND** | プルダウン抵抗の片足、電池マイナス | グランド |

> **💡 電池接続**:
> 単4アルカリ電池×2本 (直列 3.0V) を、ボードの 3.3V ピン (または裏面のバッテリーパッド) と GND に接続します。

## 🛠 ビルドおよび書き込み手順

子機の ESP32-C3 を PC に USB 接続して作業します。

### 1. 環境変数のロード
```bash
source /home/kusa/esp/esp-idf/export.sh
```

### 2. 子機ディレクトリへ移動してビルド
```bash
cd /home/kusa/ドキュメント/eSp32/SwitchBot+sensor/outdoor_sensor
idf.py build
```

### 3. 書き込み & シリアルモニタ
```bash
idf.py -p /dev/ttyACM0 flash monitor
```

## ⚡ 動作仕様 & 特長

1. **RTC メモリによる Wi-Fi チャンネル自動記憶**:
   - 前回送信が成功したチャンネルを Deep Sleep 中も保持。
   - 普段は **0.01〜0.02秒 (1回の送信)** で完了し、最速でスリープに戻ります。
   - ルーターのチャンネルが変わった場合のみ、自動で 1〜13ch を再スキャンして記憶を更新します。
2. **単4電池2本で約 1.5〜2 年駆動**:
   - Deep Sleep 時の消費電流: 約 40 µA
   - 5分間隔の間欠動作により電池交換の手間を最小化。
3. **親機自動連携**:
   - 送信データは親機 (`90:DA:72:8B:23:FC`) に届くと、自動的に Google Home (Matter) および Web ダッシュボードに反映されます。
